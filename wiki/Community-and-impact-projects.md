## OpenClaw Guided Install

**Repo:** [aigovops-foundation/openclaw-installer](https://github.com/aigovops-foundation/openclaw-installer) · **Live:** <https://aigovops-foundation.github.io/openclaw-installer/> · **Stack:** TypeScript

Guided, hardened installer for the OpenClaw agent framework: a 7-step wizard, 16 host targets, 87 marketplace entries, 15 languages (including Cherokee and a Braille mode), a SHA-256 hash-chained audit log, SBOM tracking and 349 tests. Billed as the reference implementation of the Governance-as-Code standard.

**Place in the practice:** Operate gate for agent installs.

- Commons Clause is not Apache-2.0 and conflicts with the site's 'all Apache-2.0' claim.
- CI badges still point at `bobrapp/openclaw-installer`.
